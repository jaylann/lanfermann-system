# @lanfermann/ui

React components for Next.js and Tailwind CSS v4, built on [Base UI](https://base-ui.com). It
is the design system I use for my own sites and apps.

```bash
bun add @lanfermann/ui
```

```css
@import "tailwindcss";
@import "@lanfermann/ui/styles.css";
```

What the app has to provide (fonts, the root element, grounds and density) and how the system
looks and moves are in the [repository](https://github.com/jaylann/lanfermann-system).
