# Contributing

This is the design system I use for my own sites and apps. It is public so they can install it,
and so anyone can read how it is built.

If something looks off, open an issue. I read every issue and answer. A pull request is welcome
when it fixes a bug. Before you build a new component or change how one looks, open an issue
first: how the system looks and reads is my call.

The conventions are in the README, `packages/ui/DESIGN.md` and `.claude/rules/`. A pull request
passes the same checks as my own: lint, typecheck, tests, the story tests and the visual check.

Versions start at 0.x. Until 1.0, a minor version can break things, and the changelog says what.
